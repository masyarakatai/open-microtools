# Verified listings

Folder ini untuk pembuat tool yang ingin mengonfirmasi bahwa mereka mengendalikan domain atau repositori yang tercantum.

## Cara verifikasi

1. Tambahkan file YAML dari [`_template.yml`](./_template.yml).
2. Pasang teks `Listed on Open Microtools` yang menaut ke repositori ini di halaman tool atau README repositori resmi.
3. Sertakan URL bukti tersebut pada kolom `proof_url`.
4. Buka pull request. Maintainer akan memeriksa tautan tanpa meminta akses akun.

Verifikasi berarti bukti kepemilikan tautan, bukan endorsement kualitas atau keamanan tool.
